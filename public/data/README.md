# Portugal boundary asset

`portugal-boundary.geojson` is a high-resolution visual line containing only
the Portugal–Spain international land border. It is derived from Natural
Earth 10m admin-0 boundary lines; it deliberately does not include Portugal's
coastline or internal administrative boundaries.

This is a display aid, not an authoritative administrative dataset. The
authoritative source to validate for a future CAOP-derived replacement is DGT
CAOP2025, licensed CC BY 4.0, with attribution to the Direção-Geral do
Território.
